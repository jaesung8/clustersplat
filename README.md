# ClusterSplat Project Page

Website repository for ClusterSplat.

- Website: https://jaesung8.github.io/clustersplat/
- Website repository: https://github.com/jaesung8/clustersplat
- Research code repository: https://github.com/jaesung8/cluster-splat

## Development

This is a static website with no build dependencies. Edit `index.html`; keep
website assets in this repository and use relative paths for project Pages.

Preview locally:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000/.

## Deployment

GitHub Pages publishes the root of the `main` branch. The `.nojekyll` file
allows the HTML to be served without a Jekyll build.

The initial page is a placeholder. Paper links, author information, figures,
demos, and the poster will be added as the project page is prepared.
